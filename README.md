# 🚀 SkillForge AI

> AI-Powered Placement Preparation Platform

SkillForge AI is a full-stack MERN application that helps students prepare for placements using AI.

## ✨ Features

- 🤖 AI Resume Agent
- 💻 AI DSA Coach
- 🎤 AI Interview Agent
- 🔐 JWT Authentication
- 📊 Dashboard & Analytics
- 👤 User Profile

## 🛠 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI
- Gemini API
